# Проверки снимка 2026-11-05

- Основной установщик: 3 теста — чистая установка/перенос путей/повторный запуск и Agency verify, сохранение отличающегося AGENTS.md до любой записи, отказ при symlink.
- Agency: встроенный `--verify` после установки во временный HOME — 283 профиля, 18 категорий, все совпали. TOML профилей разбирается.
- Pixel installer: 2 теста — сохранение/объединение хуков, резервная копия, повторное обновление, сохранение токена с правами 0600; отказ при symlink назначения.
- Мост Pixel: 8 тестов forward/report.
- Pixel source: production Vite build и observer esbuild; 38 выбранных тестов observer/server/project/notification. Использованы уже доступные зависимости той же локальной сборки; node_modules и dist в репозиторий не включены.
- Gitleaks по двум новым снимкам: 4 совпадения в учебных security-примерах Codex (заведомо неверный bearer, публичный пример JWT, примеры curl), 1 синтетическая константа в тесте очистки HTTP-логов Pixel. Просмотрены; действующих учётных данных среди этих совпадений нет. Это не гарантия обнаружения всех возможных секретов.

Не проверены: установка npm на машине без кэша/интернета; весь интерфейс в новом аккаунте Codex; нативное доверие хукам на другом компьютере; реальная доставка Telegram; доступность всех плагинов другому аккаунту. Установщики не трогали живой пользовательский сетап. Полного аудита лицензий всех исторических скиллов не было; сторонние notices сохранены.

Полный повторный Gitleaks: 51 совпадение — 42 значения SHA-256 в манифестах, 8 учебных security-примеров (включая сохранённую DSH-библиотеку), 1 тестовая константа Pixel. Полная whitespace-проверка отмечает форматирование upstream-справочников и строку `=======` внутри текстового шаблона; исходники сохранены. Проверка новых установщиков и документации без замечаний.
