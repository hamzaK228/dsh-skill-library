# Frontend skill inventory

Reviewed on 27 November 2026. These are reusable references for the [frontend redesign playbook](FRONTEND-REDESIGN.md).

Install the portable frontend collection into Codex and Claude Code with the selective installer. The pack contains 74 new bundles and 19 existing library adaptations. Use `--skill NAME` to select individual bundles. The installer preserves local conflicts by default. When a local adaptation differs, leave it in place and select the missing skills.

```bash
python3 setup/install-repo-skills.py --frontend --dry-run
python3 setup/install-repo-skills.py --frontend
python3 setup/install-repo-skills.py --frontend --verify
```

Existing adaptations keep their current entrypoints and invocation policies. Upstream references include capabilities already delivered by official plugins, sources whose distribution terms or runtime dependencies need separate handling, and article aliases. References do not run installation commands or connect tools.

The bundles were reviewed as files. The review covered source and license, linked instructions, manual invocation, and steps that can read private data, install packages, run hooks, or change a destination. Dependencies, connected accounts, and example workflows have their own prerequisites.
