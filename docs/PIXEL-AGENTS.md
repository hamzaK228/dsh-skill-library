# Pixel Agents + Codex observer

Репозиторий содержит переносимый **исходный код** локального форка Pixel Agents: офис, каталог Agency Agents, проекты, планы задач, отчёты «Сделал / Делает / Дальше» и необязательные Telegram-уведомления. Это отдельный локальный наблюдатель, а не встроенный плагин Codex. Модели и агенты сами по себе здесь не запускаются.

## Установка (Linux / macOS)

Нужны Python 3.11+, Bash, Node.js **22.12+** и npm. Windows: используйте WSL; нативная установка Windows не проверялась.

Из корня скачанного репозитория:

```bash
python3 pixel-agents/install.py --scope "$HOME/projects" --install-hooks
cd ~/.local/share/pixel-agents
bash build-observer.sh
python3 ~/.local/share/pixel-agents-codex/start.py
```

`--scope` должен указывать существующий каталог проектов; можно повторять. Не выбирайте корень диска без необходимости. Установка копирует исходники и мост, генерирует новый приватный токен, сохраняет конфигурацию в `~/.config/pixel-agents-codex`. Сборка скачивает зависимости через `npm ci --ignore-scripts`, если `node_modules` ещё нет. Скрипты установки зависимостей не запускаются. Сервис автоматически не включается.

Скрипт без `--install-hooks` не меняет Codex. С ним существующие хуки сохраняются, создаётся резервная копия `hooks.json`, добавляются только события моста. Доверие не переносится: просмотрите и разрешите хуки через штатный `/hooks` в совместимом Codex, затем при необходимости перезапустите чат. Возможность хуков зависит от версии и среды Codex; облачные сессии не подключаются к локальному серверу автоматически.

Оставьте процесс запущенным и откройте офис:

```bash
python3 ~/.local/share/pixel-agents-codex/open-office.py
```

Адрес: `127.0.0.1:4312`. Для работы интерфейса нужен приватный токен в ссылке; не пересылайте её. Остановка: Ctrl+C в терминале сервера. Занятый порт требует остановить другой экземпляр. Автозапуск при входе можно настроить отдельно после проверки.

Повторная установка требует `--update`; она объединяет исходники, сохраняет токен и состояние, но заменяет список разрешённых scopes на переданный. После обновления заново выполните сборку. Перед откатом/обновлением сохраните свою копию исходников. Чтобы отключить мост, удалите только команды `pixel-agents-codex/forward.py` в `~/.codex/hooks.json` и остановите процесс; остальные хуки сохраняйте.

## Отчёты и приватность

В AGENTS.md своего пользователя добавьте правило: во время согласованной работы передавать краткий отчёт локальному наблюдателю через `python3 ~/.local/share/pixel-agents-codex/report.py`, JSON в stdin с ровно тремя однострочными строками `done`, `current`, `next` (до 280 символов каждая). Запускать из исходной рабочей папки чата, не подменять `CODEX_THREAD_ID`. При завершении `current` и ненужный `next` пустые. Не включать секреты или содержимое файлов.

Мост передаёт только метаданные событий (идентификаторы сессии/инструмента/агента, тип инструмента, рабочую папку, время). Тексты запросов, результаты инструментов и транскрипты не пересылаются. Явные отчёты содержат именно переданный агентом текст. Наблюдатель читает локальный индекс проектов Codex для имён/идентификаторов в пределах scopes. Планы хранятся в localStorage браузера, состояние уведомлений — в приватной папке конфигурации. В комплекте нет истории, токенов, проектов, скриншотов частного рабочего стола или пользовательских внешних ассетов.

Telegram подключается **отдельно** в интерфейсе: собственный бот, привязка частного чата, явное включение. Реальная доставка не проверялась при подготовке комплекта. Полный паритет возможностей зависит от доступности нативных хуков и формата локального индекса Codex.
