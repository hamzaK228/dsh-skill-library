# DSH Skill Library · portable Codex setup

Переносимый снимок моего сетапа на **6 ноября 2026**: **95 локальных скиллов Codex**, **283 профиля Agency Agents**, исходники доработанного **Pixel Agents** и список **35 плагинов/компонентов Codex** с инструкциями подключения. Исходная библиотека **91 скилла DSH** сохранена отдельно.

## Быстрый старт

Нужны Git, Python **3.11+** и установленный Codex. Для Pixel Agents дополнительно Node.js **22.12+**, npm и браузер.

```bash
git clone https://github.com/hamzaK228/dsh-skill-library.git
cd dsh-skill-library
python3 setup/install.py --dry-run
python3 setup/install.py
python3 setup/install.py --verify
```

Установщик копирует `codex/skills/`, `codex/agents/` и шаблон инструкций в `~/.codex/`. Заменяет пути исходного компьютера на домашнюю папку получателя. Не меняет `config.toml`, авторизацию, MCP, плагины, службы и хуки. Одинаковые файлы пропускает, при отличающемся файле или симлинке прекращает работу **до записи**. Для другого профиля используйте `--home /path/to/home`.

Если `~/.codex/AGENTS.md` или скиллы уже существуют и отличаются, сначала установите комплект в отдельную папку через `--home`, затем вручную объедините нужные инструкции и файлы. Автоматического перезаписывания нет. После установки откройте новый чат Codex: наличие профилей на диске не гарантирует, что текущая сессия уже видит их.

## Остальные части сетапа

- **[Шесть интеграций репозиториев](docs/REPO-INTEGRATIONS.md)** — Graphify, Agent-Reach, MiroFish, Paperclip, VoiceStudio и Open SEO: скиллы для Codex и Claude Code, выборочная установка с резервными копиями, отдельная настройка CLI и приложения.

- **[Pixel Agents: установка и запуск](docs/PIXEL-AGENTS.md)** — локальный офис, наблюдение за агентами, отчёты, задачи, календарь и отдельная настройка Telegram. Это наблюдатель; назначение задачи в календаре само не запускает агента.
- **[Плагины](docs/PLUGINS.md)** — установите через каталог Codex и подключите свои аккаунты. Их приватные серверы, проприетарный код и права доступа репозиторий не переносит.
- **Agency Agents** входят в основную установку: `agency-team` выбирает минимальную полезную команду после согласования задачи; профили и исходные MIT-материалы находятся в `codex/`.
- **[Исходный DSH-сетап](docs/DSH.md)** — отдельная библиотека в `skills/`, её каталог в `CATALOG.md`. Это другая среда; Codex-адаптации находятся в `codex/skills/`.

В настройках сохранены согласование новой задачи, экономия токенов, ограничения ручного вызова скиллов и отчёты в Pixel Agents. Модели, тарифы, доступ к внешним сервисам и возможности приложения выбираются получателем. Личные проекты, чаты, память, ключи, токены, Telegram-привязка и браузерные данные исключены.

## Проверки

```bash
python3 -m unittest discover -s setup -p 'test_*.py'
python3 setup/install.py --home /tmp/my-codex-setup --dry-run
```

`setup/manifest.json` фиксирует SHA-256 всех файлов Codex-снимка. Установщик проверяет их перед копированием; `--verify` сравнивает установленный комплект после подстановки путей. Исходный Agency-манифест сохранён как provenance; `portable-hashes.json` позволяет встроенному Agency-установщику проверять профили после переноса домашних путей.

## Структура и происхождение

| Путь | Содержимое |
|---|---|
| `codex/skills/` | Локальные Codex-версии со всеми supporting files |
| `codex/agents/` | 283 профиля Agency |
| `setup/` | Установщик, инструкции, манифест, список плагинов и тесты |
| `pixel-agents/` | Снимок Pixel Agents и моста Codex без состояния |
| `skills/`, `tools/`, `CATALOG.md` | Исходная библиотека DSH |

Каждый сторонний компонент сохраняет свою лицензию; общей перелицензировки нет. См. [NOTICE.md](NOTICE.md), локальные LICENSE/SOURCE-NOTICE и provenance внутри скиллов. Для плагинов без права распространения включены только сведения об установке.
